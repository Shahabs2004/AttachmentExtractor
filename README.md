# استخراج‌گر پیوست‌های Outlook

> ابزار دسکتاپ ویندوز برای **جست‌وجو، فیلتر و استخراج انبوه پیوست‌های ایمیل‌های Microsoft Outlook** — با تقویم شمسی، فیلترهای تودرتوی AND/OR، قالب‌بندی مسیر و گزارش خروجی.

این برنامه بازنویسی مدرن و کامل ابزار قدیمی Delphi است و با **C# / .NET 10 / WPF** و رابط کاربری فارسی راست‌به‌چپ ساخته شده است. برنامه هیچ سیستم فعال‌سازی، نسخه آزمایشی یا محدودیت زمانی/تعدادی ندارد.

## معرفی

بسیاری از سازمان‌ها و کاربران، فایل‌های مهم خود را در پیوست ایمیل‌های Outlook نگهداری می‌کنند. پیدا کردن و ذخیره دستی صدها پیوست از میان هزاران ایمیل، کاری زمان‌بر و پرخطاست. این ابزار با اتصال به **Outlook دسکتاپ کلاسیک** از طریق COM، ایمیل‌های پوشه‌های انتخابی را اسکن می‌کند، امکان فیلتر دقیق بر اساس فرستنده، موضوع، تاریخ شمسی، اندازه، پسوند و ده‌ها معیار دیگر را می‌دهد و پیوست‌های انتخاب‌شده را با ساختار دلخواه روی دیسک ذخیره می‌کند.

ویژگی‌های کلیدی در یک نگاه:

- کاملاً **فقط-خواندنی** نسبت به صندوق پستی؛ هیچ ایمیلی تغییر نمی‌کند، حذف نمی‌شود و Outlook بسته نمی‌شود.
- **بدون نیاز به نام کاربری/رمز جداگانه**؛ از پروفایل و احراز هویت موجود Outlook استفاده می‌کند.
- **بدون محدودیت**؛ نه تریال، نه فعال‌سازی، نه سقف تعداد یا حجم.
- **اجرای محلی**؛ هیچ داده‌ای به اینترنت ارسال نمی‌شود.

## امکانات

### اتصال و اسکن

- اتصال به Outlook دسکتاپ کلاسیک (Microsoft 365، Outlook 2021/2019/2016).
- نمایش درخت کامل پوشه‌ها با انتخاب سه‌حالته (تیک کامل/نیمه/بدون تیک)، دکمه «همه»، «هیچ‌کدام» و انتخاب سریع «صندوق ورودی».
- اسکن اختیاری زیرپوشه‌ها و امکان محدودکردن نتایج به ایمیل‌های دارای پیوست.
- نمایش زنده پیشرفت (تعداد ایمیل اسکن‌شده/منطبق) و امکان **لغو** در هر لحظه.
- تشخیص خودکار پیوست‌های **Inline** (تصاویر امضا و محتوای جاسازی‌شده) بر اساس خصیصه‌های MAPI مانند `PR_ATTACHMENT_HIDDEN` و `PR_ATTACHMENT_CONTENT_ID` و کنار گذاشتن آن‌ها به‌صورت پیش‌فرض.
- استخراج آدرس SMTP واقعی فرستنده‌های Exchange از طریق `PropertyAccessor` (به‌جای آدرس‌های `/O=...`).

### فیلتر حرفه‌ای

- **فیلتر سریع** با فیلدهای آماده: بازه تاریخ شمسی/میلادی، فرستنده، دامنه، گیرنده (To/CC)، موضوع، متن ایمیل، پسوند، حداقل/حداکثر اندازه، حداقل تعداد پیوست، اهمیت، دسته‌بندی، فقط دارای پیوست و فقط خوانده‌نشده.
- **پریست‌های آماده**: ۷ روز اخیر، ۳۰ روز اخیر، امسال، سال گذشته.
- **ویرایشگر فیلتر پیشرفته** با گروه‌بندی نامحدود تودرتو و عملگرهای AND/OR.
- اعتبارسنجی هوشمند: جلوگیری از اسکن با گروه خالی یا شرط ناقص و نمایش پیام خطای دقیق.
- ترکیب فیلتر سریع و پیشرفته با AND؛ یعنی ایمیل باید همه شرایط سریع و کل درخت پیشرفته را هم‌زمان برآورده کند.
- امکان **فعال/غیرفعال کردن کلیدواژه‌های جست‌وجو در متن ایمیل** (در صورت نیاز، بدنه ایمیل به‌صورت خودکار خوانده می‌شود).

### انتخاب و پیش‌نمایش

- جدول نتایج با ستون‌های موضوع، فرستنده، تاریخ شمسی، پوشه، نشانگر پیوست و حجم کل.
- انتخاب تک‌تک ایمیل‌ها، «انتخاب همه» و «انتخاب هیچ‌کدام».
- پنل جزئیات با سه زبانه:
  - **پیوست‌ها**: فهرست پیوست‌های همان ایمیل با انتخاب/عدم انتخاب هر فایل.
  - **متن ایمیل**: پیش‌نمایش بدنه (فقط هنگام باز شدن خوانده می‌شود).
  - **گزارش**: لاگ عملیات اسکن و خروجی.
- انتخاب پیش‌فرض پیوست‌ها: همه پیوست‌های غیر Inline؛ اگر ایمیل فقط پیوست Inline داشته باشد، همه آن‌ها انتخاب می‌شوند.

### خروجی

- پنج ساختار پوشه: مسطح، بر اساس فرستنده، بر اساس تاریخ (شمسی)، بر اساس پوشه Outlook و قالب سفارشی.
- قالب نام فایل با توکن‌های غنی (تاریخ شمسی، فرستنده، موضوع، شماره پیوست و…).
- سه سیاست تداخل نام: تغییر نام خودکار (`file (1).pdf`)، رد کردن فایل موجود، یا بازنویسی.
- حفظ تاریخ دریافت ایمیل روی فایل خروجی (اختیاری).
- پشتیبانی از مسیرهای طولانی ویندوز با پیشوند `\\?\`.
- گزارش CSV و JSON از نتیجه خروجی (به‌صورت اختیاری).
- باز کردن پوشه مقصد پس از پایان (اختیاری).

### پروفایل‌ها

- ذخیره ترکیب کامل فیلتر سریع + پیشرفته با یک نام.
- بارگذاری، حذف و جایگزینی پروفایل.
- **ورود و خروجی پروفایل** به‌صورت فایل JSON برای انتقال بین سیستم‌ها.

## دریافت و اجرا

### گزینه ۱: نسخه آماده

از بخش **Releases** مخزن، فایل `AttachmentExtractor-vX.Y.Z-win-x64.zip` را دانلود، استخراج و فایل `AttachmentExtractor.exe` را اجرا کنید. برنامه **portable** است و نصب‌کننده نمی‌خواهد.

> فایل اجرایی امضای دیجیتال ندارد؛ ویندوز ممکن است پیام SmartScreen نمایش دهد. با «More info → Run anyway» ادامه دهید.

### گزینه ۲: ساخت از سورس

```powershell
git clone https://github.com/YOUR-USERNAME/AttachmentExtractor.git
cd AttachmentExtractor
dotnet build AttachmentExtractor.slnx -c Release
dotnet run --project src/AttachmentExtractor.App -c Release
```

### گزینه ۳: انتشار تک‌فایلی خودکفا

```powershell
dotnet publish src/AttachmentExtractor.App/AttachmentExtractor.App.csproj `
  -c Release `
  -r win-x64 `
  --self-contained true `
  -p:PublishSingleFile=true `
  -p:IncludeNativeLibrariesForSelfExtract=true `
  -o publish/win-x64
```

خروجی در پوشه `publish/win-x64` قرار می‌گیرد. (همین دستور در ورک‌فلوی GitHub Actions نیز اجرا می‌شود.)

## شروع سریع

1. Outlook دسکتاپ را باز کنید (ترجیحاً یک‌بار پروفایل را باز کنید تا آماده باشد).
2. برنامه را اجرا کرده و روی **«اتصال به Outlook»** بزنید.
3. روی **«بارگذاری پوشه‌ها»** بزنید و پوشه‌های موردنظر را تیک بزنید.
4. فیلتر سریع را پر کنید یا با **«فیلتر پیشرفته»** درخت شرایط خود را بسازید. پروفایل دلخواه را ذخیره کنید تا بعداً یک‌کلیک بازیابی شود.
5. **F5** یا دکمه **«اسکن ایمیل‌ها»** را بزنید.
6. در جدول نتایج، ایمیل‌ها را بررسی و انتخاب کنید و در پنل جزئیات، پیوست‌های موردنظر را تیک بزنید.
7. مسیر مقصد و تنظیمات خروجی را مشخص کنید و **Ctrl+E** یا **«ذخیره پیوست‌های انتخاب‌شده»** را بزنید.
8. پس از پایان، خلاصه نتیجه (ذخیره‌شده/رد‌شده/ناموفق) در نوار پایین و زبانه «گزارش» نمایش داده می‌شود.

## فیلترها

### فیلتر سریع

فیلدهای فیلتر سریع به‌صورت خودکار به شرط‌های AND تبدیل می‌شوند:

| فیلد | نوع | توضیح |
|---|---|---|
| از تاریخ / تا تاریخ | تاریخ | شمسی (`1404/08/11`) یا میلادی (`2025-11-02`) |
| فرستنده | متن | بخشی از نام یا ایمیل فرستنده |
| دامنه فرستنده | متن | مثال: `company.com` |
| گیرنده | متن | جست‌وجو در To و CC |
| موضوع | متن | بخشی از موضوع |
| متن ایمیل | متن | جست‌وجو در بدنه (کندتر) |
| پسوند | متن | لیست جدا با کاما؛ مثال: `pdf, docx` |
| حداقل/حداکثر اندازه | عدد (MB) | اندازه پیوست |
| حداقل تعداد پیوست | عدد | مثال: `1` |
| اهمیت | انتخاب | Low / Normal / High |
| دسته‌بندی | متن | دسته‌بندی Outlook |
| فقط دارای پیوست | چک‌باکس | پیش‌فرض فعال |
| فقط خوانده‌نشده | چک‌باکس | — |

### فیلتر پیشرفته (تودرتو)

ویرایشگر پیشرفته اجازه می‌دهد هر تعداد **گروه** و **شرط** بسازید؛ هر گروه می‌تواند شامل شرط یا گروه دیگری باشد:

```text
AND (ریشه)
├── دامنه فرستنده = company.com
├── تاریخ دریافت ≥ 1405/01/01
└── OR
    ├── پسوند پیوست = pdf, docx
    └── اندازه پیوست ≥ 2 MB
```

این درخت یعنی: «ایمیل‌های شرکت در بازه مشخص که یا پیوست PDF/DOCX دارند یا پیوستی بزرگ‌تر از ۲ مگابایت».

**فیلدهای قابل استفاده:**

| فیلد | نمونه مقدار |
|---|---|
| موضوع، متن ایمیل | `گزارش فروش` |
| فرستنده، نام فرستنده، ایمیل فرستنده | `ali@company.com` |
| دامنه فرستنده | `company.com` |
| گیرنده (To/CC)، To، CC | `manager@company.com` |
| مسیر پوشه | `Inbox\Projects` |
| تاریخ دریافت، تاریخ ارسال | `1404/08/11` یا `2025-11-02` |
| نام پیوست | `report` |
| پسوند پیوست | `pdf, xlsx` |
| اندازه پیوست، اندازه ایمیل | `2.5 MB`، `500 KB` |
| تعداد پیوست | `1` |
| دارای پیوست، خوانده شده | بدون مقدار |
| اهمیت | `High` یا `2` |
| دسته‌بندی | `Finance` |

**عملگرها:**

| نوع فیلد | عملگرها |
|---|---|
| متنی | شامل، شامل نباشد، مساوی، نامساوی، شروع با، پایان با، **Regex**، در لیست (`In`)، در لیست نباشد |
| تاریخ | قبل از، بعد از، ≥، ≤، بین دو تاریخ، مساوی، نامساوی |
| عدد/اندازه/تعداد | =، ≠، >، <، ≥، ≤، بین دو مقدار |
| بولی | درست است، نادرست است، مساوی، نامساوی |
| اهمیت | =، ≠، در لیست، در لیست نباشد، >، < |

**نکته درباره شرط‌های سطح پیوست:** شرط‌هایی مانند «پسوند پیوست» یا «اندازه پیوست» در سطح **ایمیل** ارزیابی می‌شوند؛ یعنی اگر **حداقل یک** پیوست با شرط مطابقت داشته باشد، ایمیل منطبق است. عملگرهای منفی (مثل «شامل نباشد») زمانی درست‌اند که **هیچ** پیوستی شرط مثبت را برآورده نکند. پس از اسکن، همه پیوست‌های غیر Inline ایمیل‌های منطبق به‌صورت پیش‌فرض انتخاب می‌شوند و می‌توانید در پنل جزئیات، پیوست‌های ناخواسته را از انتخاب خارج کنید.

**قالب مقادیر:**

- تاریخ: `1404/08/11` (شمسی) یا `2025-11-02` (میلادی)؛ زمان هم پشتیبانی می‌شود.
- اندازه: `2 MB`، `2.5MB`، `500 KB`، `1 GB` یا عدد خالص (به‌معنای مگابایت).
- لیست‌ها: با کاما جدا شوند: `pdf, docx, xlsx`.
- Regex فقط برای فیلدهای متنی و پسوند، با مهلت اجرای ۱ ثانیه برای جلوگیری از الگوهای کُند.

## انتخاب پیوست‌ها

- کلیک روی هر سطر ایمیل، پیوست‌های آن را در زبانه «پیوست‌ها» نشان می‌دهد.
- چک‌باکس هر پیوست تعیین می‌کند آیا در خروجی ذخیره شود یا نه.
- پیوست‌های Inline به‌صورت پیش‌فرض تیک ندارند (مگر اینکه ایمیل هیچ پیوست معمولی نداشته باشد).
- دکمه‌های «همه» و «هیچ‌کدام» در نوار بالای فهرست پیوست‌ها و همچنین انتخاب گروهی ایمیل‌ها در جدول نتایج موجود است.
- ایمیل‌های انتخاب‌نشده در جدول، در خروجی شرکت داده نمی‌شوند.

## خروجی و ساختار پوشه‌ها

| ساختار | نتیجه |
|---|---|
| مسطح (Flat) | همه فایل‌ها مستقیماً در پوشه مقصد |
| بر اساس فرستنده | زیرپوشه به نام ایمیل فرستنده (یا نام او در صورت نبود ایمیل) |
| بر اساس تاریخ | `<سال شمسی>\<ماه شمسی>` مثل `1405\08` |
| بر اساس پوشه | تکرار مسیر پوشه Outlook مثل `Inbox\Projects` |
| سفارشی | مسیر ساخته‌شده با قالب دلخواه شما |

**سیاست تداخل نام:**

| سیاست | رفتار |
|---|---|
| تغییر نام (Rename) | افزودن پسوند عددی: `Report (1).pdf` |
| رد کردن (Skip) | فایل موجود دست‌نخورده می‌ماند و پیوست جدید ذخیره نمی‌شود |
| بازنویسی (Overwrite) | فایل موجود با نسخه جدید جایگزین می‌شود |

> نام فایل‌ها و پوشه‌ها به‌صورت خودکار از کاراکترهای غیرمجاز ویندوز پاک‌سازی می‌شوند و مسیرهای بلندتر از حد مجاز با پیشوند `\\?\` پشتیبانی می‌شوند.

## قالب‌های مسیر و نام فایل

### توکن‌های قالب نام فایل

| توکن | مقدار |
|---|---|
| `{OriginalName}` | نام اصلی پیوست |
| `{BaseName}` | نام فایل بدون پسوند |
| `{Extension}` | پسوند همراه با نقطه (`.pdf`) |
| `{Ext}` | پسوند بدون نقطه (`pdf`) |
| `{Sender}` | نام نمایشی فرستنده |
| `{SenderEmail}` | ایمیل فرستنده |
| `{SenderDomain}` | دامنه ایمیل فرستنده |
| `{Subject}` | موضوع ایمیل |
| `{Folder}` | نام پوشه Outlook |
| `{Date}` / `{Date:yyyy-MM-dd}` | تاریخ میلادی دریافت |
| `{JalaliDate}` / `{JalaliDate:yyyy-MM}` | تاریخ شمسی دریافت |
| `{Year}`، `{Month}`، `{Day}` | اجزای تاریخ میلادی |
| `{JYear}`، `{JMonth}`، `{JDay}` | اجزای تاریخ شمسی |
| `{Index}` | شماره پیوست در ایمیل |
| `{MessageKey}` | هش ۸ کاراکتری از شناسه ایمیل (برای نام‌گذاری یکتا) |

مثال‌ها:

```text
{JalaliDate:yyyyMMdd}-{BaseName}
{SenderEmail}\{JalaliDate:yyyy-MM}\{OriginalName}
{Subject}-{Index}{Extension}
```

> اگر قالب نام فایل فاقد توکن پسوند باشد، پسوند اصلی به‌صورت خودکار اضافه می‌شود.

### توکن‌های قالب پوشه سفارشی

همان توکن‌ها در قالب پوشه هم قابل استفاده‌اند؛ با این تفاوت که `{Folder}` در قالب پوشه، **مسیر کامل** پوشه Outlook را تولید می‌کند. مثال پیش‌فرض:

```text
{SenderEmail}\{JalaliDate:yyyy-MM}
```

## گزارش خروجی (Manifest)

در صورت فعال بودن گزینه «ساخت گزارش CSV و JSON»، دو فایل در ریشه مقصد ساخته می‌شود:

```text
attachment-manifest-14050811-124923.csv
attachment-manifest-14050811-124923.json
```

**ستون‌های CSV** (UTF-8 با BOM برای نمایش صحیح در Excel):

`ردیف`، `وضعیت`، `تاریخ دریافت`، `فرستنده`، `ایمیل فرستنده`، `موضوع`، `مسیر پوشه`، `نام پیوست`، `اندازه (بایت)`، `مسیر ذخیره`، `خطا`

**ساختار JSON:**

- `Summary`: تعداد کل پیوست‌ها، ذخیره‌شده، رد‌شده، ناموفق، حجم ذخیره‌شده، وضعیت لغو، زمان شروع/پایان، مقصد، ساختار، قالب نام فایل و سیاست تداخل.
- `Entries`: فهرست کامل ردیف‌ها با جزئیات هر پیوست و خطای احتمالی.

## پروفایل‌ها و تنظیمات

### پروفایل فیلتر

- ذخیره ترکیب **فیلتر سریع + درخت فیلتر پیشرفته** با یک نام.
- بارگذاری با انتخاب از فهرست؛ پاک کردن فیلترها با دکمه مربوطه.
- **ورود/خروجی** فایل `*.json` برای انتقال تنظیمات بین سیستم‌ها.
- پروفایل‌ها در `%AppData%\AttachmentExtractor\profiles.json` نگهداری می‌شوند.

### تنظیمات برنامه

مسیر مقصد، ساختار، قالب‌ها، سیاست تداخل، ساخت گزارش، حفظ تاریخ، باز کردن پوشه، اسکن زیرپوشه‌ها، فقط دارای پیوست و آخرین پروفایل، به‌صورت خودکار ذخیره می‌شوند:

```text
%AppData%\AttachmentExtractor\settings.json
```

در صورت بروز خطای غیرمنتظره، فایل `%AppData%\AttachmentExtractor\error.log` ایجاد می‌شود.

## امنیت و حریم خصوصی

- **صندوق پستی فقط خوانده می‌شود:** برنامه هیچ ایمیل، پیوست، پرچم یا پوشه‌ای را تغییر نمی‌دهد و حذف نمی‌کند.
- **Outlook بسته نمی‌شود:** برنامه هرگز `Outlook.Quit()` را فراخوانی نمی‌کند؛ نمونه Outlook باز شما دست‌نخورده می‌ماند.
- **بدون اعتبارنامه ذخیره‌شده:** از پروفایل و احراز هویت موجود Outlook استفاده می‌شود؛ هیچ رمز یا توکنی در برنامه ذخیره نمی‌شود.
- **بدون ارتباط شبکه‌ای:** برنامه هیچ درخواست HTTP، تلمتری یا آنالیتیکس ندارد؛ همه عملیات محلی است.
- **آزادسازی منابع COM:** تمام اشیای COM پس از استفاده آزاد می‌شوند تا Outlook پایدار بماند.

## معماری پروژه

```text
AttachmentExtractor.slnx
├── src/
│   ├── AttachmentExtractor.Core/       # مدل‌ها، موتور فیلتر، تاریخ شمسی، مسیرها، مانیفست
│   │   ├── Abstractions/               # IMailSource
│   │   ├── Filters/                    # FilterEvaluator، Validator، Analyzer، Catalog
│   │   ├── Models/                     # FilterNode، MailMessageInfo، ExportOptions، ...
│   │   ├── Services/                   # OutputPathBuilder، PathTemplateRenderer، ManifestWriter، ...
│   │   └── Utilities/                  # LongPath، ValueParsers، TextNormalizer
│   ├── AttachmentExtractor.Outlook/    # اتصال COM به Outlook (late binding) در ترد STA
│   │   ├── OutlookMailSource.cs
│   │   ├── StaWorker.cs
│   │   └── ComHelper.cs
│   └── AttachmentExtractor.App/        # اپلیکیشن WPF فارسی RTL (MVVM)
│       ├── ViewModels/
│       ├── Views/
│       ├── Converters/
│       └── Resources/Theme.xaml
└── .github/workflows/build.yml         # ساخت و انتشار خودکار
```

- **Core** کاملاً مستقل از Outlook است و موتور فیلتر/مسیر/مانیفست را بدون وابستگی به COM نگه می‌دارد.
- **Outlook** تمام فراخوانی‌های COM را روی یک ترد اختصاصی STA انجام می‌دهد و از الگوی آزادسازی `Marshal.ReleaseComObject` پیروی می‌کند.
- **App** با MVVM دست‌ساز (بدون پکیج خارجی) و قالب ظاهری سفارشی ساخته شده است.

## ساخت و انتشار خودکار با GitHub Actions

فایل [`.github/workflows/build.yml`](.github/workflows/build.yml) دو کار انجام می‌دهد:

1. **ساخت در هر Push/Pull Request** به شاخه‌های `main` یا `master` و اجرای دستی:
   - نصب .NET SDK 10
   - Restore و Build کل Solution در حالت Release
   - Publish خودکفا و تک‌فایلی برای `win-x64`
   - بارگذاری خروجی به‌عنوان Artifact با نام `AttachmentExtractor-win-x64` (قابل دانلود از تب Actions)
2. **انتشار نسخه در هر Tag** مانند `v1.0.0`:
   - ساخت همان خروجی
   - ساخت فایل ZIP
   - ایجاد **GitHub Release** با نام تگ و پیوست فایل اجرایی و یادداشت‌های خودکار

انتشار نسخه جدید:

```powershell
git tag v1.0.0
git push origin v1.0.0
```

> تگ‌های شامل خط تیره (مثل `v1.1.0-beta`) به‌صورت Pre-release منتشر می‌شوند.
